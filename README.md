# SCT_DA_Task3

## Task 3: Interactive Visualization

Created an interactive HR Employee Attrition Analysis Dashboard using Power BI.

### Dashboard Features
- Total Employees
- Employees Who Left
- Attrition Rate
- Attrition by Department
- Attrition by Job Role
- Attrition by OverTime
- Attrition by Job Satisfaction
- Attrition by Age Group
- Interactive filters for Department, Gender, Job Role, and Age Group

### Dataset
IBM HR Analytics Employee Attrition & Performance dataset.

### Tool Used
Microsoft Power BI Desktop
